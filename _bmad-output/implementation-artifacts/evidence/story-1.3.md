# Story 1.3 验证结果

2026-11-24（Asia/Shanghai）。macOS，Java 21.0.12.1，Node.js 24.12.0，H2 2.2.224，Flyway 10.10.0。使用独立临时 H2 文件库。HTTP 断言通过 Spring MockMvc 运行，加载实际 Spring Security 过滤链及 JDBC 配置。页面通过 Vue 组件渲染验证，使用可控的请求结果覆盖错误和恢复。

| 验证项 | 实际结果 |
| --- | --- |
| 构建 | Vue 类型检查、Vite 生产构建与 Maven 离线打包均通过。 |
| V1 升级与重复迁移 | 已含管理员账号的 V1 文件库应用 V2；再次迁移无待应用版本。目录恰有 10 张卡，字符串标识按 `1` 至 `10` 排序，型号均为 `RTX 4090`。业务表为 `accounts` 和 `gpus`。 |
| 权限、建号与读目录 | 未登录读取为 401；已有管理员登录后读取为 200，创建成员为 201；新成员使用同一登录入口读取为 200，响应字段仅 `id`、`model`。退出为 204，Session 失效，随后读取为 401。 |
| 刷新与应用上下文重启 | 重复读取结果一致。关闭并重建 Spring 应用上下文，使用同一 H2 文件库重新登录，目录响应与首次读取完全一致。 |
| 读取失败和恢复 | 临时重命名测试库的 GPU 表，读取得到无正文的 503；恢复表名后重查得到原目录。Vue 页面在请求中显示加载提示，网络中断及 503 时显示重试提示并隐藏列表，重试成功后恢复全部十行。 |
| 页面约定 | 成员页面显示 GPU 1 至 GPU 10、型号及名额和确认开始的说明。页面提供刷新目录和退出入口。 |

## Safari 页面与应用进程验收

2026-11-24（Asia/Shanghai）。沿用 Story 1.1 和 1.2 的 Safari 页面验收环境。使用 Safari 27.0.1、Java 21.0.12.1、既有演示 JAR 和独立 H2 文件库。为验证网络中断，在浏览器与真实应用之间使用仅监听本机的测试代理。

| 验收项 | 实际结果 |
| --- | --- |
| 重复迁移、建号与访问控制 | 首次应用 V1、V2，重复迁移无待应用版本。管理员在 Safari 登录并查看目录，网页建号返回 201。退出后目录返回 401，新成员使用同一入口重新登录，目录返回 200。匿名读取返回 401。 |
| 目录、使用约定与刷新 | Safari 显示 GPU 1 至 GPU 10，每个标识唯一，型号均为 RTX 4090，页面展示名额与硬件占用的区别和先确认开始的约定。API 仅返回字符串 `id` 和 `model`。点击刷新目录和重新加载页面后，列表及 API 响应均一致。 |
| 加载、网络中断与重试 | 暂停目录请求时，Safari 显示加载提示并禁用刷新按钮。测试代理断开该请求后，页面显示失败提示并隐藏列表。恢复连接并点击重试后，10 行全部恢复，API 响应与首次读取一致。 |
| 应用进程重启 | 停止第一轮 JVM（PID 2980）并确认端口停止监听。使用同一 H2 文件库启动第二轮 JVM（PID 2991）。Safari 刷新后回到登录页，旧会话读取目录返回 401。原成员重新登录成功，目录仍有 10 行，API 响应逐字节相同。 |

Safari 验收通过，专用浏览器会话和应用进程均已结束。

## Chrome 补充验证

同日使用 Java 21.0.12.1、另一独立 H2 文件库和 Chrome 157.0.8103.79 的无头模式运行演示 JAR。

| 验收项 | 实际结果 |
| --- | --- |
| 固定目录与重复迁移 | 首次启动前执行 V1、V2；重复迁移报告无待应用版本。停服后只读查询确认目录有 10 行、10 个唯一标识，范围为 1 至 10，型号均为 RTX 4090。 |
| 管理员建号与成员登录 | 管理员在网页登录并查看目录，创建测试成员返回 201。退出后，成员使用同一入口登录。页面显示成员身份、GPU 1 至 GPU 10 和两条使用说明。目录接口只返回字符串 `id` 和 `model`。 |
| 访问控制 | 匿名读目录返回 401，管理员和成员读取均返回 200。退出返回 204，随后读目录返回 401。 |
| 刷新与错误恢复 | 点击刷新目录和重新加载网页后，列表及 API 响应均一致。在 Chrome 暂停目录请求时，页面显示加载提示并禁用刷新按钮。模拟网络中断后，页面显示重试提示并隐藏目录。解除拦截并点击重试后，恢复 10 行与原响应。数据库读取失败及恢复见上方验证记录。 |
| 应用进程重启 | 第一轮 JVM（PID 2057）停止，H2 连接池关闭且端口停止监听。以同一 H2 文件库启动第二轮 JVM（PID 2170）。旧会话被拒绝，原成员重新登录成功，目录仍显示 10 行，API 响应与首次读取逐字节相同。 |

验收结束后已确认测试服务停止。服务日志未包含测试口令或 `JSESSIONID`。结合上方构建、数据库错误和页面交互记录，Story 1.3 验收通过。
