# 名额生命周期操作

与 PRD、AD-1–6、AD-8 配套使用。所有操作在权限校验后按实际目标和已保存状态处理。后继名额每次使用独立 allocation_id。

## 按卡开始

- 成员确认本人指定名额开始。保留原分配和到期时刻，其他卡不受影响。该操作记录成员的网页声明。
- 已开始的有效名额返回已处理，保留首次 started_at。已结束名额返回失效或已处理，不影响后继。任何既存异常事实保留，开始与必需记录同事务。

## 按卡归还

- 成员确认完成后立即结束本人对应名额，记录 RETURNED，无需管理员审批。其他卡或等待项保持原状态。
- 结束原名额、更新当前映射、存在合法等待项时对队首分配并写入必需审计和消息，均在同一事务完成。
- 重复归还返回已结束，首次结束时刻和后继名额均保持，业务消息及审计不重复。

## 管理员核实释放

- 管理员提交原 allocation_id、所见状态、确认及非空理由。未开始异常需核实可释放，已开始逾期需核实任务完成。
- 目标仍有效但所见状态变化时返回 409 并刷新确认。已结束时无变化。核实释放、后继分配、审计及双方必需通知同事务。

## 成员续期与审核

- 成员为仍有效的本人名额提出明确期望期限。提交、待审或拒绝均不延时。管理员批准的明确新期限须严格晚于当前期限和应用当前时间。仍有效的逾期名额可延期，续期无单次或累计上限。
- 审批只作用于原名额。先延期则后来到期检查使用新期限，先释放则审批失效。只标异常或逾期且保留映射时可以继续续期。
- 按最新已批准 expires_at 减原 allocated_at 判定短时。6 小时延至 12 小时，到期未开始释放；延至 24/30 小时，原分配满 24 小时未开始标异常并保留。原分配、开始和历史异常不被清除。
- 首次审核结论保留，重复相同结论返回已处理，反向改判返回 409。仍有效但所见状态或期限变化时刷新确认。期限、结论、审计及本人通知同事务。续期后新一轮逾期可产生新通知。

## 管理员直接延期

- 无需成员先申请。管理员提交原名额、所见状态与期限、明确新期限和非空理由。期限须严格晚于当前期限和应用当前时间。已结束名额不可延期，重复指定已生效的相同期限没有额外变化。
- 保留名额身份、持有者和原分配、开始及异常事实。所见状态或期限已变化且仍需变更时返回 409。以直接延期记账，期限、审计及持有者通知同事务。

## 管理员代成员归还

核实已开始任务完成或未开始名额可释放，提交原 allocation_id、所见状态和理由。仍有效但状态变化时返回 409 并刷新核实。审计记录真实管理员和代归还，原名额以 RETURNED 结束。结束、后继获配、审计及必需通知同事务。

## 管理员主动撤销

管理员提交原名额、所见状态及理由。可撤销未完成任务的名额，界面提示管理员线下通知原持有者并协调交接。仍有效但所见状态变化时返回 409 并刷新确认。原名额结束、合法后继获配、审计和必需通知同事务。旧撤销对后继无效。
