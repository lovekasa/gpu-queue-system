# 本人收件箱与已读交互

由bmad-spec依据.memlog.md和已确认的D036提炼，来源为Story2.8的7组验收。与PRD及架构配套使用，非实现或测试结果。

- 收件箱显示已提交的本人业务消息，包括已交付的获配、异常、逾期、自动释放和管理员核实处理；后续管理员功能继续复用此收件箱。
- 明确点击“标记已读”后才保存单条消息的read_at；单纯查询列表不改状态。本期不增加批量标记、标回未读或删除能力。
- read_at持久化且保留首次值。重复标记返回已读或无变化，不影响其他消息或新产生的未读记录。
- 所有读取和标记按Session收件人归属校验；写入保留CSRF。管理员也不能通过本人收件箱接口任意读取他人消息。
- 历史消息仍可读、可标记，不改消息正文、原审计、名额或队列，不重新触发分配或通知；消息不是访问后继持有者详情的入口。
- 加载/写入失败不伪装成空列表或成功；重查按持久化事实显示，不记录凭据或Session。
