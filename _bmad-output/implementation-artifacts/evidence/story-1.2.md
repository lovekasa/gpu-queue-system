# Story 1.2 验证记录

2026-11-22（Asia/Shanghai），在 Apple Silicon macOS 使用 JDK 21.0.12.1、Maven 3.9.16、Node.js 24.12.0 和现有锁文件。Vue 类型检查、Vite 构建和 Maven 打包通过。API 和 Safari 验收使用各自独立的临时 H2 文件库。API 验收库路径为 `/var/folders/9x/bkwvhwq96kx5_7f07c9jl9fm0000gn/T/gpu-queue-test-members-wc7l_136/gpu-queue.mv.db`。验收后已停止应用。

| 验收 | 实际结果 |
| --- | --- |
| 1. 合法创建 | 按运行手册迁移、初始化并启动。管理员带有效 CSRF 向 `POST /api/admin/members` 提交表单，返回 201，仅含账号 ID、规范化登录名、姓名、MEMBER 角色。附加管理员角色字段也只创建 MEMBER。Safari 显示创建成功、规范化登录名和姓名。 |
| 2. 无效输入 | 空白登录名、空白姓名、空口令和超长登录名或姓名均返回 400，并指明错误字段。Safari 在登录名旁显示空白输入错误。 |
| 3. 重复建号 | 大小写和首尾空白变体与已有成员、管理员分别冲突，均返回 409。Safari 显示登录名已存在。原成员仍可使用原口令登录，原姓名和角色保持不变。 |
| 4. 认证、角色与 CSRF | 匿名请求带有效 CSRF 返回 401，管理员缺少 CSRF 返回 403，成员携带有效 CSRF 和伪造角色返回 403。 |
| 5. 成员登录 | 新建成员经原登录入口登录返回 204，身份接口返回 200 和该成员姓名、登录名、MEMBER 角色。错误口令返回 401。Safari 显示成员身份，页面无建号表单。 |
| 6. 写入失败 | 启动前，仅在临时库加入拒绝指定测试登录名的 H2 CHECK 约束。该账号创建返回 503，响应无敏感内容，随后登录返回 401。停机后只读查询确认全库仅一位管理员和一位成员，成员姓名与角色正确，口令散列符合 96 位十六进制格式，无无效请求写入的记录。 |
