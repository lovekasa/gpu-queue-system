# 紧急审核与人工调序

与 FR-005、FR-007、AD-6、AD-7 配套使用。

## 紧急审核

- 紧急申请待审或拒绝时按普通规则排队，原提交时间和接收顺序保留。批准后只有仍在等待的卡采用紧急排序，等待严格超过 72 小时仍优先。
- 已获配的卡不追溯重排或改期限。全部卡已获配时只记录审核结果及对应审计、通知。
- 首次审核结论保留。重复同一结论返回已处理，反向改判返回 409。批准、拒绝均需非空理由，结论、审计及站内消息同事务。
- 公开队列仅显示姓名、顺序，不公开他人审核详情。

## 人工调序

- 管理员提交单卡当前等待项、目标位置、所见有序列表及非空理由。当前顺序与所见不同则返回 409，刷新后再确认。
- 先应用基础排序，再按移动操作记录 ID 执行 AD-7 的锚点重放。原后继优先、原前驱备选、均不存在则不移动。提交年龄、接收顺序和紧急结论保持。
- 当前项及位置实际变化的在排成员收到各自的位置变化和原因，同一成员每次变化只收一条。无变化时不新增移动规则、成功审计或业务通知。
- 目标项离队后移动失效，新申请不继承，原审计保留。移动、前后顺序审计及全部必需消息同事务。
