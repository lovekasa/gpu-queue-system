# Epic 1 Context: 成员安全进入系统并识别指定资源

<!-- Compiled from planning artifacts. Edit freely. Regenerate with compile-epic-context if planning docs change. -->

## Goal

为实验室 GPU 名额系统建立可独立演示的受控访问基础：管理员初始化并登录、创建成员账号，成员登录后识别10张指定4090及使用约定。权限、真实数据库和可重复启动流程随功能一起交付，为后续申请与名额模块提供稳定身份及资源入口；本史诗不交付申请、分配或训练执行。

## Stories

- Story 1.1: 初始化应用并以受控管理员身份登录
- Story 1.2: 管理员创建成员账号
- Story 1.3: 成员查看指定 GPU 与使用约定

## Requirements & Constraints

- 提供管理员和成员两种身份。账号由管理员建立，不开放自行注册或公开管理员初始化；成员建号入口只创建成员，不接受客户端角色升级。
- 初始管理员由运维受控步骤建立；重复初始化不得覆盖现有口令或追加授权。口令安全散列存储，凭据、散列、Cookie和Session不得出现在响应、日志、版本库或测试证据中；成员初始凭据通过系统外方式交付。
- 登录名规范化在创建与登录中保持一致，数据库唯一约束保护重复及并发创建，冲突不得改写既有账号。具体输入规则在实现前记录，前端校验不能替代服务端校验。
- 权限验证覆盖合法操作和绕过页面的拒绝场景；不能以全部拒绝通过验收。退出后原会话失效，登录失败不得创建有效会话或泄露敏感账号信息。
- 固定目录含GPU 1至GPU 10，各卡标识稳定且唯一；重复种子步骤、刷新和重启不得改变标识或产生重复记录。资源读取仅向已登录成员或管理员开放，不附带账号凭据或其他成员详情。
- 页面描述使用名额，不宣称实测空闲、利用率或任务数。系统不接SSH、不执行或终止训练、不监测真实占用；成员获配后先网页确认开始，再自行运行任务。
- 独立测试库验证持久化、重启、认证、角色、CSRF及失败反馈；保存可复核步骤与实际结果。本史诗仅证明已实现入口，后续管理员干预、本人数据归属及名额竞争仍须随对应功能验收。

## Technical Decisions

- 保持Vue 3、Spring Boot 3.3.13、Java 21、本地MySQL InnoDB模块化单体；官方create-vue初始化前端。工程创建前实测Java、Maven、Node及MySQL服务端，记录并锁定前端、构建工具和新增依赖精确版本；客户端版本不能代替服务端证据，不能静默升级确认基线。
- 单Spring Boot应用、同源页面/API；开发前端代理API，正式访问使用HTTPS。Spring Security负责Session、口令散列和CSRF，Cookie为HttpOnly；本机HTTP开发配置与正式Secure Cookie配置分开。逐API验证角色，不能以隐藏按钮代替授权。
- 账号模块拥有账号和角色；后续名额写入由唯一名额服务负责，不为管理员入口建立绕过事务的通道。当前只引入账号必需结构，GPU目录随资源故事引入；禁止预建申请、排队、名额、续期等未来业务表。
- 实施前写清持久化访问与迁移工具选择；数据库结构使用版本化迁移，由明确单次步骤执行，禁止运行期自动改表。连接或迁移失败须明确失败，不假装启动成功。
- dev、test、demo数据库和账号隔离，应用权限限于对应库，测试不得写真实申请数据。第一版单实例，不增加Redis、消息队列或微服务。
- API标识用字符串，时间为带Z的ISO 8601；数据库UTC会话、DATETIME(6)，页面Asia/Shanghai。未认证401、无权限403、状态冲突409、非法输入400，按认证与CSRF实际语义返回。

## UX & Interaction Patterns

- 管理员完成受控初始化后从登录页进入显示本人身份的受保护首页；退出后回到需登录状态，错误凭据给出无敏感信息的反馈。
- 管理员填写登录名、显示姓名、初始口令建号；成功仅显示账号必要信息，字段错误可辨认。新成员复用同一登录入口，显示成员身份，不能进入管理员建号功能。
- GPU目录展示固定标识、类型和使用约定；有可辨认的加载、失败与重试恢复状态，不能以虚构空闲或成功数据掩盖错误。没有独立视觉设计契约，布局与组件由对应故事细化。

## Cross-Story Dependencies

- 1.1无前序依赖，独立完成初始化、登录及退出演示；1.2复用其账号存储和认证；1.3复用前两者，交付建号到成员识别资源的演示。
- Epic 2复用身份、Session和固定GPU行，后续同卡事务需要稳定资源主键；Epic 1不依赖后续名额接口即可验收。
