# 架构约定质量门复核

日期：2026-11-18。对象：ARCHITECTURE-SPINE.md 草稿；仅文档审阅，未执行数据库或业务测试。

## 总体结论

三个目标风险已有足够明确的共同事务入口、固定资源行锁、唯一当前映射及独立名额身份。权限、运行环境和恢复路径也有覆盖。人工调序的持续锚点规则仍可能产生相互矛盾的约束，应收敛为一个确定性的队列重建算法后再作为后续故事的共同契约。

## 严重发现

- **High — AD-7 的持续锚点与多次调序没有统一的冲突消解规则。** AD-7 同时要求“被移动项保持与其仍在排相邻锚点的关系”和“多次移动按 transition_seq 顺序重放”。例：普通顺序 A、B、C，先移动 C 到 A 与 B 之间，再把 B 移到 A 前；C 的持续关系要求 A<C<B，而第二次移动要求 B<A，形成环。顺序重放可得到 B、A、C，但它不满足 C 被要求持续保持的锚点关系。两个模块可分别选择持续约束求解与操作重放，都能援引原文却得到不同结果。**修正：**明确锚点只是每次顺序重放操作时的定位提示，不是永久偏序约束；指定锚点单个/两个失效或反序时的精确退化规则，并明确后一次移动优先。若选择改变人工调序的业务持续语义，应提示该行为并由需求负责人确认。
