# 成员账号供给约定

来源：D027，用户已接受的Story1.2；本文由bmad-spec从.memlog.md提炼，与PRD及架构共同使用。

- 管理员登录后填写登录名、成员显示姓名和初始口令，创建的角色固定为成员。该入口不提供额外管理员授权。
- 凭据通过系统外方式交给本人，本期不增加邮件、短信或密码找回模块。
- 登录名按一个明确的共用规则规范化并保证唯一，创建与登录使用同一口径；具体输入格式在实现前写清。
- 口令只保存安全散列，账号查询、创建响应及日志不返回初始口令或散列；验证证据不暴露凭据。
- 并发或重复创建同登录名最多留下一个账号，冲突不覆盖既有姓名、口令或角色；普通成员不能建号或通过伪造角色提升权限。
- 新成员复用已有认证入口即可登录，建号功能不依赖未来申请或资源故事。

此文件补充已确认建号交互，不表示故事已实施或测试通过。
