# 成员查看指定 GPU 与使用约定

依据 FR-001、FR-002、AC-002-1 的固定标识及名额说明、FR-009 的先确认开始约定、NFR-002、AD-1 和 AD-8。已登录的成员和管理员均可查看目录。

- Flyway V2 创建 `gpus`，以整数主键固定标识 1 至 10，种子型号为 `RTX 4090`。Flyway 按版本执行，重复执行迁移命令仅检查已应用版本。
- `GET /api/gpus` 按标识数值排序，返回 `id`（字符串）和 `model`。缺少有效 Session 返回 401，数据库读取失败返回无响应正文的 503。后续按卡申请使用同一 `id`。
- 登录页验证身份后展示 GPU 目录，包含加载、失败、重试和刷新状态。页面说明系统管理指定 GPU 的使用名额，名额记录不代表硬件真实占用。获配后先在网页确认开始，再自行登录服务器运行任务。
